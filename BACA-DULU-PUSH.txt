LANGKAH PUSH (± 5 MENIT)
------------------------
1. Extract zip ini.
2. Buka folder "web-orvelion-prod" hasil extract.
3. Select SEMUA isinya (Ctrl+A) lalu Copy.
4. Paste ke DALAM folder repo kamu (folder yang ada .git-nya).
   Kalau ditanya, pilih Replace / Overwrite SEMUA.
5. Hapus file "orvelion-optimasi.bundle" di repo kamu kalau masih ada.
6. Buka terminal di folder repo kamu, jalankan tiga baris ini:

      git add -A
      git commit -m "Optimasi lengkap: PJAX, gzip, ETag, micro-cache, WAL, transisi fade"
      git push

7. Selesai! Buat memastikan berhasil: buka GitHub, cek bahwa file-file ini ADA:

      static/js/pjax.js
      orvelion/optimizations.py
      PANDUAN-OPTIMISASI.md

   Kalau ketiganya kelihatan di GitHub = BERHASIL.
